Classes

Action
One command, declared once and registered into every chat the bot is in.
ActionError
An action failing for a reason the person who typed it should read.
ActionRegistry
The catalogue of every action the bot knows, and the single place every adapter looks when it wires itself up.
Arguments
The arguments to one command invocation, parsed the same way on both surfaces.
ChatDispatcher
Runs commands typed in a connector's own chat — Twitch chat, a Telegram group.
ChatInvocation
Somebody typing a command in a connector's own chat, as far as the {@see ChatDispatcher} needs to know.
Context
Everything an action knows about the invocation it is servicing: who asked, from where, what they are allowed to do, and — the interesting part — which room on which network the action should act upon.
Cooldowns
How long somebody must wait before running the same command again.
DiscordAdapter
Registers the action catalogue into DiscordPHP's `MessageCommandClient`, as prefix commands.
Slash
How an {@see Action} presents itself as a Discord slash command.
SlashAdapter
Registers actions that carry a {@see Slash} spec as Discord slash commands.
SlashOption
One typed parameter of a slash command.
Surface
Which chat an action was invoked from, and what that chat can take.
