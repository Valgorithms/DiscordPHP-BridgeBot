GatewayDiagnostics
in package
  • Application

FinalYes
GatewayDiagnostics.php : 32

Turns a Discord gateway close code into something you can act on.

DiscordPHP logs not reconnecting - critical op code and puts the code in the record's context, which a log line that prints only the message throws away. What is left says the bot stopped and nothing about why — and the two most common causes have completely different fixes that look identical from the outside: the bot connects, identifies, and is dropped a second later.

Every string here names the specific thing to change, because "authentication failed" sends people to re-copy a token that was never the problem.

fromLogContext()

GatewayDiagnostics.php : 129

Pulls the close code out of a log record's context.

public static fromLogContext(string $message, array<string, mixed> $context) : int|null

DiscordPHP is the only thing that knows the code, and it only ever reports it by logging — there is no event to listen for — so reading it back off the record is the one hook available without patching the library. Returns null for anything that is not a fatal gateway close, which is every other record the logger will ever see.
