Media.php : 28

A picture or a file attached to a message.

url is deliberately nullable, and the difference matters. A Discord attachment arrives with a CDN link anyone can open; a Telegram photo arrives as a file id, and turning that into a URL means asking the Bot API — which returns a link with the bot token in the path. So a connector that can only offer such a link hands over null and keeps the token to itself, and the relay falls back to uploading the bytes or naming the file.
