`/bridge` — the commands that are about the bot rather than about any one network.

help and about would be the obvious names, and that is exactly the problem: they are the names every bot in a server wants. Qualifying them is not pedantry here, it is the same rule that keeps two connectors from colliding, applied to the core so that it cannot be the exception.
