ComponentRouter
in package
  • Application

FinalYes
ComponentRouter.php : 37

Routes button and select-menu presses by `custom_id`.

DiscordPHP can attach a listener to a Button instance, but that listener lives in the process that built the button. A panel posted before a restart would go dead, and every panel would hold a closure for as long as the message existed. The bridge instead encodes what a button does into its custom_id and routes on that, so a panel from last week still works and the process holds one handler per action rather than one per message.

Ids look like tg:unlink:1234567890: a fixed prefix so another bot's components are ignored, an action, then arguments. Discord caps a custom_id at 100 characters, which is enforced when one is built rather than discovered when Discord rejects the message.
