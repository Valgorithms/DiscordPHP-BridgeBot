implements ProvidesActions uses UsesTwitch

FinalYes
ApiActions.php : 50

`api` — the rest of Helix.

The named commands elsewhere in this directory cover what a chat actually asks for day to day. This covers everything else: every method of every TwitchPHP repository, reachable by name, with arguments matched to parameters and the response rendered back into chat.

api list                                  every repository
api list moderation                       every call on one
api help moderation.warn                  its signature
api moderation.warn broadcaster_id=1 moderator_id=2 user_id=3 reason=spam

Gated to Access::Operator — not to the broadcaster, and not to moderators. This reaches endpoints that ban users, end streams and rewrite a channel, and it does so with the bot's own token; the rung below it is a badge anyone can be given by someone who is not thinking about that.
