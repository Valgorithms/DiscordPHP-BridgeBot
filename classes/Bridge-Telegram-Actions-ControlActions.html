ControlActions
in package
  • Application
implements ProvidesActions uses UsesTelegram

FinalYes
ControlActions.php : 47

What the bridge can do *to* a Telegram chat, beyond relaying into it.

These were /tg when Telegram was the only network this bot knew. They are /telegram chat … and /telegram mod … now, which is not decoration: send and ban are words another connector will want, and a bare /tg alongside /twitch invites the question of which one pin belongs to.

All of them act on the chat the invoking Discord channel is bridged to — Context::requireTarget() resolves that — which is what makes the unprivileged ones safe to leave open: they can only ever reach a chat someone with Manage Server already linked to that channel.
