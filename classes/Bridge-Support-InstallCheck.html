InstallCheck
in package
  • Application

FinalYes
InstallCheck.php : 31

Reads the application's install settings back and says what is wrong with them, once, at startup.

Who can add the bot to a server is decided in the Developer Portal, not in this process — and it decides a great deal. Whoever can link a room in any server the bot is in can reach every Twitch channel and Telegram chat the bot can, so a bot anyone can add is a bot anyone can point at those rooms. The portal says nothing when it is left that way, so this does.

Pure: it takes the application as Discord returned it and hands back findings, so it can be tested without a connection.
